# Installation

## Requirements

*   `python` 3.11 or newer
*   `spaCy` 3.7 or newer
*   `numpy`, `scipy`, `pandas`

The dependencies are installed with the package. A language library built on anyTS installs it as its own dependency.

## From PyPI

``` bash
pip install anyts
```

## From the repository

``` bash
git clone https://github.com/SergeyShk/anyTS.git
cd anyTS
uv sync --all-groups
```
